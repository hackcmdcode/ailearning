Glossary of AI Terms (Aâ€“Z Essential Dictionary)

👤 AI Academy Editorial Team 📅 Updated July 2026 ⏱ 20 min read

Use this reference dictionary to quickly look up key technical terminology across artificial intelligence, machine learning, neural networks, and generative models.

A

Activation Function: A mathematical function applied to a neuron's output to introduce non-linearity into a network. Common examples include ReLU, GELU, and Sigmoid. See How Neural Networks Work.

Agent (AI Agent): An autonomous software system that uses an LLM to perceive inputs, formulate plans, and call external tools to accomplish goals. Read AI Agents Explained.

Attention Mechanism: A technique enabling neural networks to dynamically focus on specific parts of an input sequence when generating outputs.

B

Backpropagation: The fundamental algorithm for training neural networks, using the calculus chain rule to compute error gradients backward from the output layer. See Neural Networks Guide.

Bias (Algorithmic): Systematic distortion in AI outputs caused by biased training data or modeling assumptions. Read AI Ethics and Bias.

C

Context Window: The maximum number of tokens an LLM can retain in active memory during a single prompt interaction. Learn more in What is an LLM?.

Convolutional Neural Network (CNN): A deep neural network architecture designed for grid data like images. See Computer Vision Basics.

F & L

Fine-Tuning: Additional training performed on a pre-trained model using a smaller, specialized dataset.

Large Language Model (LLM): A massive neural network trained on vast text corpora to perform language understanding and generation. Read LLM Guide.

P & R

Prompt Engineering: Structuring inputs to elicit optimal performance from generative models. See Prompt Engineering Complete Guide.

Retrieval-Augmented Generation (RAG): Connecting an LLM to external vector databases to retrieve grounded facts before generating answers.
